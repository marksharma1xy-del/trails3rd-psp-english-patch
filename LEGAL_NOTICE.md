## What this repository contains

## What this repository deliberately does NOT contain
- The game (ISO, EBOOT, data files) or any extracted game assets.
- The official English script by XSEED Games, or any file extracted from the GOG release.
- Decompiled game scripts.

## How the XSEED English text is used
Much of the game's dialogue and many menu tables already exist in official English in the **PC (GOG) release**.
This project does not copy that text into the repository. Instead, the build tool reads it **from the user's own legally purchased GOG installation**, on the user's own computer, and ports it into the PSP data.
